BLAST and HMMER for EnzymeX — procedure and parameters

Vansh Sehrawat  ·  4 August 2026

Procedure

  1. Export from a copy of enzymesdata in a read-only session. Keep Swiss-Prot and PDB rows, drop invalid sequences, collapse exact duplicates.
  2. Write the FASTA and a metadata file holding EC number, source and description.
  3. makeblastdb over the FASTA.
  4. Cluster the FASTA with MMseqs2, apply QC gates, align each surviving cluster with MAFFT, then hmmbuild and hmmpress. EC labels are attached after clustering.
  5. Stamp every artifact with one build ID. Steps 1–4 run offline.
  6. A submitted sequence is validated, then run through blastp, phmmer and hmmscan against those artifacts. No database connection at search time.
  7. Hits are annotated from the metadata file of the same build and shown as three separate tables.

Parameters

blastpBLAST+ 2.16.0  ·  -evalue 1e-3  -comp_based_stats 2  -max_target_seqs 500  -outfmt 6 (13 fields)  ·  top 25 ranked in application code
phmmerHMMER 3.4  ·  -E 1e-3  --tblout  --domtblout
hmmscanHMMER 3.4  ·  -E 1e-3  --tblout  --domtblout  ·  against the pressed profile database
ClusteringMMseqs2 easy-cluster  --min-seq-id 0.35  -c 0.80  --cov-mode 0  --cluster-mode 0
ProfilesMAFFT --auto --anysymbol  ·  hmmbuild --amino -n  ·  hmmpress
Validation runBLAST+ 2.5.0  ·  -evalue 1e-5  -comp_based_stats 2  -max_target_seqs 100  -outfmt 6  -num_threads 16 (Beomsu's settings)
max_target_seqs 500: it is a search-time cutoff, not a best-N filter, so ranking to 25 is done afterwards in code.   hmmscan rather than hmmsearch: hmmsearch computes E-values against the submitted set, so one protein would score differently depending on what was pasted alongside it.

Known limits

Fusion constructsA GFP query returns 25 PDB fusion hits at up to 97.5% identity; 15 carry an EC across 8 values, none belonging to GFP. Query coverage 1.00 against subject coverage 0.55 exposes it. Subject coverage is computed from merged HSP intervals because BLAST+ does not report it.
Profile coverageProfiles cover only QC-passing clusters, so an absent hmmscan hit is not evidence of absence.
Data sourceEvery figure above comes from a public proxy dataset, not the EnzymeX table. Schema, key and source labels still need verifying against the real copy.
